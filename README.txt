CBQ ERP Connect Demo - local copy with the white (light) theme as default

Copied from https://sumeetonline90.github.io/CBQ_Banking/ on 2026-11-19. The live site is unchanged.

Only change: index.html now starts in the light theme (data-theme="light"). The theme button in the top bar still switches between light and dark.

HOW TO OPEN
The demo uses JavaScript modules, so it must be served by a small local web server; double-clicking index.html will show a blank page.

Option 1 (Windows, Python installed): double-click start-demo.bat, then keep the black window open while you use the demo.
Option 2 (Node.js installed): open a command prompt in this folder and run:  npx serve .
Option 3 (VS Code): open this folder and use the Live Server extension.

Then open http://localhost:8080 (or the address the tool shows).
Fonts and icons load from the internet, so stay online.
